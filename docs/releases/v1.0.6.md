MC 服务器 v1.0.6，完善 Forge 启动兼容和 Java 运行时错误诊断，新增完整服务端包导入、管理面板、模组下载及手机端自签名。

## 启动与稳定性

- 兼容 Forge 的 `-jar …-shim.jar` 参数文件：读取 JAR 清单中的主类和依赖，避免将 `-jar` 传给嵌入式 JVM 导致 `Unrecognized option: -jar`，同时保留其他 JVM 参数和程序参数。
- Java 运行时准备增加跨进程文件锁；失败时显示所处步骤、异常类型，并在控制台与日志中保留完整原因链，避免只显示空白的“JRE 准备失败”。
- Java 8/17 按需下载并校验，下载后可离线使用；Java 21/25 继续随应用提供。
- 控制台日志与慢客户端解耦，避免大量日志阻塞服务器输出和状态；存档确认优先送达，历史日志不会被当作新的存档确认。

## 服务器管理

- 导入完整服务端 ZIP 或目录，保留目录结构，并识别 JAR、Forge/NeoForge 参数文件和简单启动脚本中的 Java 入口。
- 独立管理面板，提供文件编辑、复制/移动、压缩解压、玩家与权限、模组/插件、世界与整服备份、日志和定时任务。
- 模组下载支持 Modrinth 搜索、兼容版本选择、必需依赖预览和校验下载；本地列表支持名称与启用状态筛选。
- 设置页可使用 Android Keystore 在手机本地修改当前 APK 的包名并重新签名，随后安装或导出。新包名使用独立数据；签名证书须保留在生成应用的数据中，官方应用更新后需重新生成副本。

## 下载与安装
