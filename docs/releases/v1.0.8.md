# MC 服务器 v1.0.8

- 重做首页和运行控制台，使用统一的橙色主题。首页可直接查看服务器状态、进入管理面板或打开控制台。
- 新增 8 张内置封面。未设置封面的服务器会在启动时抽取一张。可选用内置图、导入本地图片，或恢复自动模式。已有的 `server-icon.png` 可作为服务器封面。
- 首页直接显示作者名称、B 站主页和 QQ 群入口。
- 控制台支持暂停和恢复日志跟随。小屏横放时，局域网地址可从菜单查看并复制，为日志留出更多空间。

## 下载与安装

`mcmobileserver-1.0.8-arm64-v8a.apk` 适用于 ARM64 设备，要求 Android 8.0 或更新版本。应用使用 `versionCode 9`，可覆盖安装使用同一发行签名的旧版本并保留已有服务器和配置。发行页附有 `SHA256SUMS.txt` 校验文件。
