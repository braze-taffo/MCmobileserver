## 验收边界

上述静态夹具不是实际 Fabric 整合包。Java 8/17 的原生执行证据来自 x86_64 模拟器，ARM64 证据为真实包校验/解压和原生库编译。真实 ARM64 手机上的复杂整合包、玩家联机、模组原生库、长时后台行为和真实 Minecraft 存档的运行中备份/定时重启，仍需实际整合包与设备验收。

整服恢复替换文件目录并保留当前实例登记和启动设置；恢复不同核心/版本时应核对启动设置。运行中保存命令无法确认时会取消备份。目录迁移将原备份位置写入实例清单，迁移后仍能通过备份面板访问和导出原备份，包括内部存储中的备份。

本地测试产物和日志在 `build/android-validation/`；debug APK 为 `app/build/outputs/apk/debug/app-debug.apk`，本地 ARM64 安装包为 `app/build/outputs/apk/release/app-release.apk`。版本元数据继续为 1.0.4（versionCode 5），未更改正式发行版本。实际手机上的覆盖安装和 GitHub 发布不是此次验证结论。
